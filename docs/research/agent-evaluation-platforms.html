评测范式分类

五大评测范式 · 评判主体与自动化程度

🤖 LLM-as-Judge（LLM 作为裁判）
用另一个 LLM 对 Agent 输出进行打分。当前最主流的范式，核心问题：偏见（Position/Verbosity/Self-enhancement）和推理成本。
代表：DeepEval G-Eval · Galileo Luna-2 · Braintrust Loop AI · LangSmith Polly AI
⚙️ Code-based / Deterministic（确定性代码评测）
通过代码规则（正则匹配、JSON Schema 校验、DAG 流程）进行确定性评判。零随机性、零 API 成本。最大局限：无法理解语义。
代表：DeepEval DAG 指标管道（最强）· Braintrust Scorer 原语 · LangSmith 自定义函数
👤 Human Eval（人工评测）
人类专家对 Agent 输出进行判定。精度最高但成本最高、扩展性最差。所有平台都支持，但深度差异大。
代表：Braintrust 人工队列 · Galileo Enterprise 工作流 · Langfuse UI 标注队列
_

_

🕵️ Agent-as-Judge（Agent 作为裁判）
用专用 Agent 对目标 Agent 的全链路行为（规划、工具调用、中间决策）进行评估。最大空白——6/9 平台完全缺失。Braintrust Loop AI 是唯一完整闭环实现。
代表：Braintrust Loop AI（完整）· DeepEval（部分）· Galileo Insights Engine（部分）
🔒 Sandbox Eval（沙箱环境评测）
在隔离环境中执行 Agent 操作（写文件、发请求、操作数据库）并评估结果。LangSmith 唯一提供完整 Docker 沙箱的评测平台——其独家护城河。
代表：LangSmith Sandbox（唯一）· Maxim AI 仿真引擎（近似）
关键发现：无平台覆盖全部 5 范式。Braintrust 和 DeepEval 最完整（4/5），两者均缺失沙箱。

场景选型

9 大场景 · 首选 + 备选 + 核心理由

🐍 Python CI/CD + 大量指标

首选：DeepEval
40+ 预构建指标 + DAG 管道 + Pytest 风格天然适配 CI/CD。Apache 2.0 开源零成本集成。备选：Braintrust。

🔗 LangChain 重度用户

首选：LangSmith
原生 LangChain/LangGraph 集成 + 步骤级评分 + 唯一 Docker 沙箱。Agent-as-Judge 空白需 Braintrust 补充。

🏠 自托管 + 数据主权 + 免费

首选：Langfuse
MIT 开源，自托管完全免费，SaaS 仅 $59/月。OTel 原生 + Trace/评估/成本追踪四合一。备选：Comet Opik（40M trace/day）。

🔄 CI/CD 闭环 + 高产出团队

首选：Braintrust
唯一完整 Agent-as-Judge（Loop AI）。自动从生产 trace 生成测试集 → 评估 → 分析 → 修复闭环。$249/月。

🛡️ 幻觉检测 + 生产安全

首选：Galileo
Luna-2 蒸馏 SLM（$0.02/1M tokens, 152ms 延迟）+ Galileo Protect 运行时拦截。Code-based 空白。

🎭 AI Agent 仿真测试

首选：Maxim AI
唯一 Simulation 引擎，在安全环境模拟 Agent 行为后再投产。In-VPC 部署满足数据敏感场景。

📊 已有 W&B 基础设施

首选：W&B Weave
传统 ML + LLM 统一管理。基础 LLM-Judge + Code + Human 三范式覆盖。适合「够用就好」。迁移成本最低。

📈 OTel 生态 + Embedding/Drift

首选：Arize Phoenix
OTel 原生 ML 可观测。Embedding 分析 + Drift 检测全市场最强。Phoenix 开源免费。适合成熟 ML Ops 组织。

💰 预算敏感 + 完整方案

首选：Langfuse 自托管
自托管 $0 / SaaS $59/月。Trace + LLM-Judge 评估 + Human 标注 + 成本追踪四合一。备选：DeepEval（完全免费）。
空白地带

五大关键空白 — 市场潜力与填补难度

①
Agent-as-Judge × 通用平台
6/9 平台（67%）完全空白。仅 Braintrust 有完整闭环。市场潜力 🔴 高，填补难度 中，预期 1-2 年填补。
②
Sandbox × 大众平台（垄断空白）
仅 LangSmith 提供 Docker 沙箱。类比早期 CI 在裸机运行测试 → 后来容器化成为标配。市场潜力 🔴 高，填补难度 高，预期 2-3 年。
③
Code-based 缺失（Galileo 专有路线）
Galileo 是唯一不支持 Code-based 的平台。用 Luna-2 低成本弥补，但在精确匹配等场景仍有缺陷。市场潜力 🟢 低，填补难度 低。
_

_

④
Simulation + Sandbox 组合（交汇空白）
Maxim 有 Simulation 无沙箱，LangSmith 有沙箱无 Simulation。黄金组合：隔离沙箱中运行仿真测试。市场潜力 🟡 中，填补难度 高，预期 2-3 年。
⑤
Agent-as-Judge + OTel 原生集成
OTel 原生平台（Arize/Opik/Langfuse）均无 Agent-as-Judge。理想方案：Agent trace → OTel Collector → Agent-Judge 评估 span tree。市场潜力 🟡 中，填补难度 中。
格局洞察：开源阵营分化为「通用可观测」（Arize/Opik/Langfuse）和「评估专精」（DeepEval）两条路线。闭源专精玩家各有不可替代性。
Why This Matters

为什么每个 AI 团队都该关注 Agent 评测

Agent 正在从「对话机器人」进化为「自主执行者」。当 Agent 开始操作数据库、发 HTTP 请求、写文件、调用内部 API，评估就不能再只看最终输出——你需要全过程验证。
评测不再是「跑个 benchmark」的事，而是生产基础设施。就像 CI/CD 测试从可选变成标配，Agent 评测也将成为每个 AI 工程团队的基本能力。
对中国 AI 团队尤其关键：
• 国内 Agent 生态缺少 LangSmith 级别的沙箱平台——这是基础设施级空缺
• 开源方案（Langfuse/DeepEval）可零成本自托管，规避数据出境的合规风险
• Agent-as-Judge 空白意味着巨大创新空间——比做第 10 个 LLM 更有价值
• 选对平台不只看范式数量，更要看「独特范式深度」——沙箱、Agent-Judge、专有评估模型
核心判断：无平台覆盖全部 5 范式，意味着当前市场仍处于早期。未来 1-2 年最可能发生的变化：(1) 可观测平台收购评估专精团队；(2) Sandbox 从 LangSmith 的护城河变成全行业标配；(3) Agent-as-Judge 从稀缺能力变成必备功能。
