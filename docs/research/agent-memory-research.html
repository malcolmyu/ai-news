01 · Paradigms Overview

六种记忆组织范式全景

Agent 记忆系统按"如何组织、存储、检索"分为 6 条技术路线，分别解决不同维度的问题。
02 · Pattern 1

Prompt 注入派 — 实时拦截 + Embedding 检索

拦截每次 LLM 调用 → embedding 检索 → 拼进 system prompt。Mem0 用余弦相似度 + 时间衰减重排序；Mem9 再加知识图谱关系推理做实体路径检索。
本质：对 RAG 的精细化改造——把文档检索替换为记忆片段检索。写操作 50ms 内完成靠流式 embedding pool 复用和异步向量写。
03 · Pattern 2

状态机派 — 虚拟上下文管理

Letta / MemGPT 把 LLM 上下文抽象成「主记忆区 + 归档区」。模型通过 archival_memory_search() tool call 主动拉取历史，不硬塞 prompt。
代价：模型必须学会「何时主动检索」。失败就会遗忘。最接近「多 session 长尾记忆」的方案，但生态不成熟。
04 · Pattern 3

经验池 — 失败/成就驱动采集

完成 → 压缩决策路径 → 写回记忆库。新任务触发 → 加载相关经验。 类似 RL 的 Experience Replay，只是经验是自然语言不是 Q-values。
Reflexion：Actor + Evaluator + Memory 三层。Evaluator 判错误 → 写入记忆 → 下次 Actor 加载 self-reflection。让模型从自己的错误中学。
Voyager（MineDojo）：技能库 = 代码 + 执行日志，复用已验证的函数。
核心哲学：99% 的对话是噪声，只存高信息密度的片段。
05 · Pattern 4

知识图谱结构化

方案跨 session

06 · Pattern 5

专用记忆中间件

将记忆抽取为独立微服务。

🔵 Zep

最成熟独立服务。异步提炼、内置知识图谱、会话自动摘要。

🟢 LangMem

LangChain 官方记忆 service。

🟣 GCP Memorystore

向量 + 关系 + 对话统一管理。
07 · Pattern 6

系统级 / 隐式记忆

  • OpenAI Memory — 全黑箱，persistent_pointer 隐式注入
  • Apple Intelligence — 端侧 on-device，隐私优先
  • Anthropic — 教模型调 memory 工具，不做自动注入
08 · Collection Strategies

四种记忆采集策略

记忆「怎么写」比「怎么存」更决定系统质量。四种策略各有取舍。

10 · Recommendation

推荐组合：Zep + GraphRAG + Reflexion

混合检索趋势：RAG 做初筛（粗召回）→ Agentic Search 做深度关联（细推理）→ 时间衰减处理记忆温热。
Zep 管 session 层（自动摘要、实体提取）+ 时间衰减温热 → GraphRAG 管深度关联检索 → Reflexion 管自我纠错。 ⚠️ 缺的那块：目前没有工具能优雅处理「多 session 长尾记忆」而不爆炸 token。MemGPT 最接近但生态不成熟。
11 · Key Insights

核心结论

🔑 没有银弹

每种范式解决不同维度的问题。Prompt 注入适合实时场景，状态机适合长会话，经验池适合学习型 Agent。

🔄 混合才是趋势

粗召回（RAG）+ 细推理（GraphRAG）+ 温热（时间衰减）的三层架构是当前最佳实践。

⚖️ 采集策略 > 存储格式

「写什么」比「存在哪」更关键。99% 的对话是噪声，事件驱动采集的信息密度最高。

🧩 长尾记忆待解

多 session 长尾记忆的 token 爆炸问题仍是开放挑战。MemGPT 的虚拟上下文管理是目前最接近的解。
