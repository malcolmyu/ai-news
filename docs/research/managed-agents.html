01 · Problem
235|

Harness 编码的假设，会随模型进化过期

236|
237| 核心洞察：Agent 的 Harness 编码了关于模型能力的假设——但这些假设随模型进化快速过期。 238|
239|
240| 示例：Claude Sonnet 4.5 过早收尾任务（"上下文焦虑"）→ 给 Harness 加 context resets → 换 Claude Opus 4.5 后行为消失 → resets 变成无用代码。

241| 结论：Harness 必须持续迭代，但硬耦合导致每次更新都大动干戈。 242|
243|
244|
245| 解决方案：把 Agent 拆成三个虚拟化组件——Session（记录）、Harness（循环调用模型）、Sandbox（执行环境）——像 OS 的 process 与 file 抽象一样，接口稳定、实现可演。 246|
