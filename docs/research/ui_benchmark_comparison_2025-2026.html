Executive Summary

概述

本报告分析四个推动 UI 设计到代码转换的基准测试：Design2Code (NAACL 2025)、UI-Bench/Ferret-UI (ECCV 2024)、MLLM as a UI Judge (2025) 和 1D-Bench (2026)。这些框架为多模态 UI 理解和代码生成建立了严格的评估协议，涵盖视觉逼真度、代码质量、迭代优化和人类感知预测。

Key Takeaway

核心判断

UI 设计到代码的自动生成正向生产级工具演进。专业化模型在有限领域表现出色，但通用 MLLM 的迭代优化能力正在快速追赶。人类对齐评估（MLLM as Judge）有望大幅降低设计验证成本。
Screen2Code 生产可用 通用模型仍需迭代 MLLM Judge 可替代 A/B 测试
