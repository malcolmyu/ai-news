LangSmith 架构解析

控制平面 + 数据平面

LangChain 公司 · SmithDB 专有引擎 · 四种集成方式 · 四种部署模式

数据流向

从追踪到洞察

  • Agent 执行 → SDK 异步回调 → 分布式收集器
  • 收集器 → 队列 → ClickHouse（追踪）+ PostgreSQL（运营）
  • SmithDB 提供 12 倍追踪查询 · 15 倍全文搜索加速

集成方式

四种接入方式

  • ① SDK 直连（Python/TS/Go/Java）
  • ② OpenTelemetry 兼容现有管道
  • ③ 框架原生（OpenAI、Anthropic、LlamaIndex）
  • ④ LangGraph 一键部署

部署模式

四种部署模式

  • 云端 SaaS — GCP us-central-1
  • 自托管 — K8s（企业版）
  • 混合部署 — SaaS 控制平面 + 自托管数据平面
  • 独立部署 — 仅 Agent 服务器
