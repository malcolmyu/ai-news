AIOS Architecture

Three-Layer Agent Operating System

Application → AIOS Kernel → Hardware · 7 Kernel Modules · System Call Interface

KERNEL DESIGN

LLM as CPU Core

  • Each LLM instance wrapped as LLMAdapter — analogous to a CPU core
  • Scheduler uses Round Robin (default) or FIFO with context interruption
  • GPU memory-aware scheduling — eliminates CUDA OOM trial-and-error

SYS CALL API

Thread-Bound Syscalls

  • 7 modules expose ~20 system calls
  • Each inherits Python Thread — concurrent execution
  • Agent queries → classified syscalls → dispatched to module queues
