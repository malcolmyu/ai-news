应用层 → AIOS 内核 → 硬件层 · 7 个内核模块 · 系统调用接口

内核设计

LLM 即 CPU 核心

  • 每个 LLM 实例封装为 LLMAdapter——类比 CPU 核心
  • 调度器默认 Round Robin，亦支持 FIFO，配合上下文中断机制
  • GPU 显存感知调度——消除 CUDA OOM 试错开销

系统调用接口

线程绑定系统调用

  • 7 个模块暴露 ~20 种系统调用
  • 每个调用继承 Python Thread——并发执行
  • Agent 查询 → 分类系统调用 → 分发到各模块队列

性能

2.1× 吞吐量

  • Reflexion + Llama-3.1-8b: 2.1× 加速
  • 在全部框架上至少持平或提升准确率
  • 已测试 2,000 个并发 Agent
