Advanced

混合搜索 (Hybrid Search)

结合稠密向量搜索与稀疏关键词搜索，recall@5 比纯向量搜索提升 30%。
from qdrant_client import QdrantClient client = QdrantClient("localhost") results = client.search( collection_name="docs", query_vector=embedding, hybrid=HybridSearch( dense=QueryVector(vector=embedding), sparse=QueryText(text=query) ) )
Advanced

Cross-Encoder 重排序

from sentence_transformers import CrossEncoder ranker = CrossEncoder( 'cross-encoder/ms-marco-MiniLM-L-6-v2') def rerank(query, passages): pairs = [[query, p] for p in passages] scores = ranker.predict(pairs) return sorted(zip(passages, scores), key=lambda x: x[1], reverse=True)
