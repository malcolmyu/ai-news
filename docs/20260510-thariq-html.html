⚡ 怎么做 03 / 03
四条实操法则（附 Prompt）
法则 01
直接说「做 HTML」
不需要 skill / 插件，一句 "make a HTML artifact" 即可开始
"Create a thorough implementation plan in a HTML file with mockups, data flow and code snippets"
法则 02
永远加导出按钮
'Copy as prompt' 把 UI 操作转回可粘贴的 prompt，形成闭环
"Make me a draggable card editor. Add a 'copy as markdown' button that exports the final ordering"
法则 03
一次一个痛点
每个 HTML 只解决一个问题：审 PR、调参数、排 ticket，用完即弃
"Build a form editor for our feature flag config. Add a 'copy diff' button that gives me just the changed keys"
法则 04
设计系统即参考
让 Claude 扫你的代码库生成 .design.html，所有后续 HTML 风格统一
"Create a single design system HTML file by pointing Claude at your codebase"
