Garry Tan：当替代方案为零时，跨越鸿沟的战略不适用

YC CEO 提出一个颠覆性框架：Geoffrey Moore 的"跨越鸿沟"理论假设买家有一个现有解决方案作参照，但当买家替代方案是零——要么死，要么手工干——鸿沟就不存在了。他以反无人机防御为例：没有可行的近距离防御方案，60% 的解决方案也比 0% 好。对创始人的启示："发货 60% 方案，客户在求着你。" 同时，GBrain v0.40.0 发布，为 OpenClaw/Hermes Agent 增加了基于 Gemini Live 的语音 agent 能力。
"Ship the 60% solution. They're begging for it."

Aaron Levie：AI 将引爆安全工程师需求浪潮

Agent 概念

Swyx 发布"Kakuna"——Agent 的代码硬化工厂

Swyx 描述了一个新 agent 概念——名叫 Kakuna：它带着 checklist 工作，只做一件事——硬化代码。让它 /plan 然后 /goal 一天，回来后功能不变，但所有无聊的生产级工作已完成 + 一份自我审计报告。灵感来自"mullet factory"——前台派对（独特可爱功能），后台黑暗（永恒生产原则）。这个概念的突破性在于：将"把原型变成生产级代码"这个重复劳动系统化为 agent 的自动化任务。

播客深度

Unsupervised Learning Ep 87：Gemini 联合负责人 Oriol Vinyals 谈世界模型、RL 与持续学习

从纯视觉数据中提取概念理解（无语言辅助）是深度学习过去十年未解的核心难题，一旦突破将是"GPT 时刻"级别的进展。Oriol Vinyals 系统性地阐述了这一前沿方向与 AI 未来的关联。
世界模型的两层含义
Vinyals 区分了两层：① 经典表示学习——将视频压缩为概念；② Omni 展现的"世界渲染器"能力——通过语言精确控制视频行为。前者是科学问题，后者是工程成果。
纯视觉学习的最大瓶颈
目前多模态训练仍依赖语言标注或联合训练——纯图像/视频自监督学习（从视频中推导出物理定律如重力）仍处于研究阶段。视频和图像中的知识还没有经历过属于它们的"GPT 时刻"。
机器人学——世界模型的天然桥梁
世界模型可为机器人提供模拟训练环境，但精确到抓取力度的物理模拟仍存巨大鸿沟。Vinyals 判断粗粒度规划和场景理解会先落地。
Agent 构建方法论：先精后广
Spark 代理的进步来自"序列发布"策略——从窄域问题开始，逐步泛化。先做精模型，再做系统，再联合优化。
评估世界模型的物理理解——一个思想实验
Vinyals 提出训练"概念解码器"来试图从世界模型的表征中输出物理规律的数学公式——如果模型真的理解了重力，它应该能输出 F=ma 这样的公式。

今日思考
Agent 学会了"做梦"——反思机制的里程碑意义
Anthropic 的 Dreaming 功能是 AI Agent 发展史上的一个标志性事件。在此之前，Agent 的状态完全依赖单次会话——每次运行都是一张白纸。Dreaming 让 Agent 在会话间拥有了"记忆和自我改进"的能力——它会回顾自己做过的事、提取模式、自我修正。这是 Agent 从"工具"向"助理"进化的关键一步：助理会从经验中学习，工具不会。当 Agent 开始积累自己的"经验库"，人类需要定义的新边界是——Agent 应该从经验中学习到什么样的"偏见"？
代码知识图谱——Agent 基础设施层的军备竞赛
GitHub Trending 被代码知识图谱统治不是偶然。AI 编程 Agent 当前最大的瓶颈不是模型能力，而是"上下文理解"——Agent 读不懂大型代码库的结构。codegraph、Understand-Anything 等工具正在解决这个问题，而 Anthropic、微软（dotnet/skills）等巨头已开始建立自己的 skill/plugin 标准。这场竞赛的赢家将定义 Agent 如何"理解世界"——不是通过更大的参数量，而是通过更高效的知识组织方式。
纯视觉学习的"GPT 时刻"尚未到来
Oriol Vinyals 的观点值得反复思考：我们确实用语言模型"蒸馏"了人类所有的文字知识，但视频和图像中的知识——从物理定律到空间推理——还没有经历过属于它们的"GPT 时刻"。目前的 AI 仍然用语言作为理解世界的"拐杖"。当我们能做到从纯视觉数据中自监督学习物理规律时，AI 对世界的理解将进入全新维度。
杰文斯悖论的新战场——AI 安全工程师的黄金时代
Aaron Levie 的判断捕捉了一个经典模式：AI 让攻击更容易 → 攻击增多 → 防御需求反而暴涨。这与工业革命时期"蒸汽机提高效率反而增加煤炭消耗"的杰文斯悖论如出一辙。AI 时代的讽刺在于：最需要的不是"AI 安全专家"，而是"懂 AI 的安全工程师"——一个同时横跨两个技能栈的稀缺角色。
今日一问：当 Agent 学会"做梦"反思、代码知识图谱成为基础设施、安全需求因 AI 而爆发、纯视觉学习仍在等待它的"GPT 时刻"——我们是否正在见证 AI 从"单点突破"转向"系统化演进"的拐点？Garry Tan 说"当替代方案为零时，先发货 60% 方案"——这句话或许不仅适用于创业，也适用于今天的 AI 产业。没有人见过 Agent 时代的终点，但先做出来的那个人，将定义游戏规则。
