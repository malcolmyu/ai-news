今日要点

GPT-6 Sol/Luna 发布，API 价格永久下调 50%

OpenAI 发布 GPT-6 的 Sol 与 Luna 两个版本，称其在写作与整体能力上大幅提升，并把 API 价格永久下调 50%，同时为 Plus、Pro 和 Business 用户账户加载一次额度重置（banked reset）。Thibault Sottiaux 的发布推文获 2.3 万赞、1512 次转发。

Claude Opus 5.5 上线，成 Claude Code 与应用默认模型

Anthropic 让 Opus 5.5 成为 Claude Code、Claude 应用（含 Cowork）的默认模型，覆盖 Pro/Max/Team 套餐，速率额度比 Opus 5 提升 25%。Boris Cherny 用它对 Claude Agent SDK 做 Lean 形式化验证，产出 16 个修复 PR。

第三方评测印证：Next.js 跑分 Opus 5.5 与 GPT-6 并列 97%

Guillermo Rauch 公布 Next.js 最新评测：Opus 5.5、GPT-6 Sol、Fable 5.1 均得 97%，Grok 4.7 得 94% 但便宜 2-7 倍。Aaron Levie 指出 token 成本正以史无前例的速度下降，把 Agent 用例推向规模化。

Bio-security is an AI Arms Race - Eric Nguyen (CEO, Radical Numerics)
在 OpenAI→Hugging Face 事件后，人们开始追问「还有什么需要担心」，而 Anthropic 的过滤机制把网络安全和生物安全列为两大重点。Radical Numerics 联合创始人 Eric Nguyen 认为：让生物能力增强的那批模型，同样也能守住防御不落后。他在斯坦福长期推进基因组语言模型（GLM），一度无人相信，最终主导了 Arc Institute 的 Evo 与 Evo 2，这些模型后来被用于合成出真正有功能的噬菌体基因组。DNA 字母表只有 4 个字符（ACTG），序列却极长（基因平均 6 万、最长 230 万、人类全基因组约 30 亿），正是三年前的长上下文突破让这一切成为可能——早于前沿实验室构建百万级上下文模型。如今 Radical Numerics 正把 GLM 扩展到远超 DNA 生成的更广生物学问题，且已能自然地泛化到 RNA 和蛋白质。
