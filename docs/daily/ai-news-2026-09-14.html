Orbs: Shifting Coding to Cloud — Quinn Slack, Amp Code
Sourcegraph 创始人 Quinn Slack 如今带领 Amp 打造「把编码搬到云端」的新范式。这集里他与 swyx 聊了 Amp 如何用 AI 智能体彻底重构软件开发：本地开发环境「已死」，取而代之的是运行在云端的沙箱「orbs」，带来更高的并行度、安全性与零摩擦；因为团队小而高度信任，Amp 干脆取消了强制 code review，改用「恢复时间优先」的哲学，几分钟内就能发出修复；软件也从「现成配置」转向「jellyware」——可由终端用户通过代码和智能体自行定制的可 fork 软件。他的核心主张是：AI 时代，臃肿的大团队反而成为负担，一个 20 人的高能动性「SWAT 小队」就能做出大公司做不成的事。
