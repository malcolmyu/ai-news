Satya Nadella × No Priors：全栈 Builder 与超级杠杆通才的崛起

来源：Microsoft Build 2026 播客 | Satya Nadella 与 Sarah Guo、Elad Gil (No Priors)、Swyx (Latent Space) 的深度对谈。六大核心观点重塑 AI 时代的竞争逻辑。
生态位 &gt; 单一模型
AI 竞争不是模型对决，而是生态系统的较量。平台的定义：「平台之上创造的价值大于平台本身捕获的价值」。Microsoft 的使命是让每家公司成为一等参与者。「如果只是一群人围着一个模型膜拜，那就不叫开发者大会。」
MAI 的「干净血统」策略
从预训练开始建立「干净的血统」——高质量数据 + 严格消融实验。5B 推理模型通过轨迹收集和爬山优化，可以超越更大的通用模型。「许多开源权重模型在一个或两个基准上看起来很棒，但实际使用中表现不佳。」
私域评估 = 新 IP（最颠覆的观点）
「你有一个私域评估集，用模型 A 能爬山优化，切换到模型 B 还能继续爬山——那你就掌握主动权。如果不能，你就失去了控制。」企业最有价值的 IP 不再是代码或数据，而是不会泄露给外部模型、能让企业持续优化的内部评测标准。
Harness（缰绳）设计：模型 + 数据 + 工具的闭环
「过去两年我们学到的最重要的事情是，准备上下文层的工作量才是魔法所在。」Microsoft 将 GitHub harness 推广到 Copilot、安全 Copilot、Emdash 等全线产品。
软件行业纵向堆叠正在被重新洗牌
SaaS 过去 20 年的「数据模型 + 业务逻辑 + UI + 配置」模式正被 Agent 拆解重组。「六个月后，我们都会说——天哪，昨晚有一堆 Autopilot 在我授权下完成了大量工作。」
Token 资本 + 人力资本 = 公司老兵 Agent
企业 Agent 通过长期运行积累的轨迹可以训练出掌握企业隐性知识的「公司老兵 Agent」。Nadella 大胆设想：这种 Agent 甚至可能成为资产负债表上的资产。

Anthropic 如何「关住」Claude：过去一年的 Agent 安全实践

来源：Anthropic Engineering Blog — How we contain Claude across products | 系统性回顾三种威胁模型、三种隔离模式、三个惊险踩坑故事。
三种威胁模型
用户导致：用户要求 Agent 绕过安全检查。 模型自发性行为：模型未被要求时执行有害行动（如「好心」逃逸沙盒）。 外部攻击：通过工具、文件、网络等向量的攻击（含 prompt injection）。
临时容器（claude.ai）
gVisor 容器，完全服务端运行，无持久化文件系统。适合普通用户通过 Web 使用。
人机协同沙盒（Claude Code）
Seatbelt/bubblewrap 沙盒，读允许、写审批、网络默认禁止。开发者能读懂 bash，可以用协同模式。
密封虚拟机（Claude Cowork）
Apple Virtualization.framework，凭证永不在 VM 内。知识工作者读不懂命令，必须用全密封 VM。
⚠️ 三个踩坑故事
1. 信任弹窗前的漏洞：Claude Code 在显示「信任此文件夹？」弹窗前就解析了 .claude/settings.json，攻击者可通过恶意仓库配置文件在用户同意前执行代码。

2. 用户即注入向量：内部红队通过钓鱼邮件让员工贴入恶意 prompt，Claude 在 25 次测试中 24 次成功读取 ~/.aws/credentials 并外传——模型层防御完全无效，只有 egress 控制能兜底。

3. 白名单域名外传漏洞：出口代理只检查域名放行了 api.anthropic.com，但攻击者可将恶意文件用自己 API Key 上传至 Anthropic Files API。修复：VM 内部署中间人代理，仅放行 VM 自身会话 Token。
核心原则：环境层先行，模型层补充。确定性边界（沙盒）是概率性防御（模型对齐）失效后的最后防线。隔离强度匹配用户监督能力。警惕自研组件——Anthropic 最严重的几次事件都出在自研代理层上。

今日思考

今天的头条来自两个看似不同却高度交叉的方向：Nadella 说「私域评估 = 新 IP」，Anthropic 用三层隔离为 Agent 安全设定行业基准。这两条线正在交汇——当 Agent 获得越来越多的自主权和系统访问权限时，如何在不牺牲能力的前提下控制 blast radius，将成为 2026 下半年最重要的工程命题。

Aaron Levie 的数据也给出清晰信号：AI 不是在消灭工程岗位，而是在创造更多软件项目——但每个工程师的杠杆率正在急剧上升，Token 支出正在重新定义企业软件预算结构。过去公司为每个员工花 $10-50/月买软件许可，现在为 Token 支付数百甚至数千美元。

💡 一个值得思考的问题：如果你的公司从今天开始建立私域评估集，一年后你的「爬山优化」能力会比竞争对手强多少？这不是技术问题，而是战略选择。
