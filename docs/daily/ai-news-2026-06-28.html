当「服务」取代「软件」，创业者该往哪走？

Peter Yang 指出资金正从纯软件流向「服务+软件捆绑」模式——人们要的是结果而非工具。Aditya Agarwal 也说「创立纯软件公司从未如此困难」。这与 GitHub Trending 上 Agent 工具包的爆发形成呼应：当 AI Agent 能无缝调用各类工具完成端到端任务时，单一的软件产品价值正在被解构。下一波机会或许不在「卖铲子」，而在「替人挖金子」。

Nikunj Kothari 的长文提供了一个不同的视角：品味来自千锤百炼。AI 有能力通过海量迭代培养「品味」——这与大多数人的直觉相反。当工具不再稀缺，真正的壁垒在于对结果的审美判断。这或许是 AI 时代创业者最需要重新思考的问题。
