今日要点
死经济理论：AI 的万亿估值只有一个接盘侠——全球 40 亿劳动力。 Owen McGrann 在「死经济理论」一文中做了一道简单算术：OpenAI 估值超过 8000 亿美元，Anthropic 从未盈利也跻身同级别估值，整个 AI 产业的基础设施投资已达数千亿。这些数字需要一个足够大的市场来消化——这个市场只能是全球劳动市场。每份投资人 PPT 里「一个 AI agent 干十个分析师」这句台词，翻译过来就是：产品即劳动替代。McGrann 指出：OpenAI 的 GDPVal 基准衡量模型在 44 个职业上的表现，AI 生产力指数瞄准投行、咨询、律师、医生这四个高薪职业——这不是在造工具，这是在瞄准你的饭碗。
Mistral 不再只是模型公司——全栈布局：计算、模型、平台、咨询。 Koen van Gilst 从巴黎 Mistral AI Now Summit 带回的核心观察：Mistral 正在搭建完整 AI 基础设施——自建 40MW 巴黎数据中心，更多数据中心在路上；主推高效、开放、可本地部署的专用小模型；发布 Vibe for Work 对标 Claude for Work。与 ASML、BNP Paribas、Amazon Alexa+ 深度合作。核心差异化：数据主权和本地部署，BNP Paribas 在比利时用 Mistral 模型在自有服务器上跑 KYC，敏感数据不出银行大门。对欧洲受监管行业来说，这是对抗美国云巨头的利器。
深度博客

死经济理论 · SQLite Agent 工作流 · MCP 争议反转 · Mistral 全栈战略

死经济理论 —「AI 的产品不是工具，是劳动替代」
Owen McGrann 在 Hacker News 上引爆的文章（718 分、893 评论）直指 AI 产业的核心矛盾：数百亿到万亿的基础设施投资，需要足够大的市场来回收。全球只有一个市场那么大——40 亿劳动人口。「Copilot」「助手」「增强」是营销话术，真正的财务模型要求人类成本中心被系统性地消除。OpenAI 的 GDPVal 基准测试 44 个职业，AI 生产力指数瞄准投行分析师、管理顾问、大律所律师、主治医生——在几个月前还无法匹敌的任务上，AI 已实现「超过 80% 对人类专家的胜率」。McGrann 警告：如果 AI 不能替代劳动，这些公司将是资本主义史上最大泡沫。
SQLite 就够了 — Agent 工作流的持久化不需要 Postgres
Obelisk 博客回应 DBOS 的「Postgres 就够了」论点，进一步主张：对大量 AI Agent 场景，SQLite 就足够。核心逻辑：持久执行的关键是工作流状态（而非计算基础设施），SQLite 提供事务性持久状态且无需独立数据库服务。搭配 Litestream 异步复制到 S3 兼容存储，每个 agent/tenant 在自己的微型 VM 中跑 SQLite，比一个大型共享系统更简单、更便宜、故障隔离更好。特别适合 AI Agent 这种突发型、实验型工作负载——一台 Obelisk 服务器 + SQLite 数据库 + Litestream 备份，就能完成工作流重放、调试和理解 agent 行为。
MCP 已死？— 然后又活了过来
Quandri Engineering 实测了自家 MCP 栈：连接 4 个 MCP 服务器（Linear、Notion、Slack、Postgres），共 77 个工具定义占用 21,077 tokens——吃掉 Claude 200K 上下文窗口的 10.5%。Linear 一个服务器就贡献了 42 个工具定义和 12,807 tokens。MCP 比直接调用 REST API 慢 3 倍（首次初始化慢 9.4 倍），且每个工具调用都需要外部服务器往返。但故事在此反转：Claude Code 火速推出了 Tool Search with Deferred Loading，按需加载工具 schema，上下文占用减少 85%+——MCP 最致命的问题被打了补丁。文章作者更新结论：上下文膨胀问题已基本解决，但性能、调试和架构问题依然存在。
Mistral AI Now Summit — 五条笔记
Koen van Gilst 从巴黎带回五点洞察：① 专用小模型在能效和速度上超越通用大模型——Document AI 做 OCR、Voxtral 驱动 Amazon Alexa+、Robostral 与 ASML 合作工业机器人；②「Agent 的 harness（编排层）就是一切」——模型不是全部，加上上下文、持久化和学习能力才是完整的 agent；③ 数据主权和本地部署是核心卖点——BNP Paribas 在比利时用自有服务器跑 KYC；④ 技能（Skills）是组织沉淀最佳实践的方式，在与 AI agent 协作中开发；⑤ 最惊喜的应用：奥地利科学院用微调 Codestral 模型解读千年古莎草纸碎片——沉睡了数十年的未发表文献被 AI 重新唤醒。
核心信号：今天的四篇博客构成了一幅 2026 年 AI 产业的全景图——最底层是经济逻辑（死经济理论），往上是基础设施选择（SQLite vs Postgres for Agents），再往上是协议之争（MCP 的生死），最顶层是企业战略（Mistral 全栈）。每一层都在快速演化，且彼此加速：经济逻辑驱动投资，投资推动基础设施标准化，标准化催生协议之争，协议之争倒逼企业战略分化。

今日思考
万亿赌局 vs 千星 skill：AI 的两个平行宇宙
今天的头条是「死经济理论」——OpenAI 估值 8000 亿，OpenAI 和 Anthropic 的估值已经接近甚至超过多数国家的 GDP。这些数字需要劳动力替代来回收。而在 GitHub Trending 榜单上，排名第一的是一个 1173 星的「生成小红书图文」的 Claude Code skill。两个世界同时存在：一个在做万亿赌局，一个在用 AI 给小红书做配图。这不是讽刺——这恰恰说明 AI 的渗透正在两个方向上同时加速：向上替代高端脑力劳动，向下扩展日常内容创作。 真正的风险不是 AI 做不到替代，而是它做到了——但替代的方式和范围，谁也说不准。
Agent 基础设施分裂：SQLite vs Postgres，MCP vs CLI
今天的技术讨论呈现一个清晰的模式：基础设施在分裂而非统一。 Obelisk 说 SQLite 就够，DBOS 说 Postgres 才够——没有标准答案，只有场景适配。Quandri 实测 MCP 在流量高时吃上下文、慢 3 倍，但 Claude Code 一天内火速修了最大的痛点（延迟加载 tool schema）——协议还没有沉淀，但迭代速度惊人。Mistral 的选择是：不做通用大模型全面竞争，而是深耕专用小模型 + 本地部署 + 行业深度合作——用数据主权换市场份额。三条路都在跑，没有人知道哪条是对的，但再过两年回头看，今天的讨论就是路标。
今日一问：如果死经济理论的逻辑成立——AI 产业必须替代劳动力才能回本——那么你现在正在做的 AI 产品/实验，是在加速这个过程，还是在寻找一条不依赖劳动替代的变现路径？
