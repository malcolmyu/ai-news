125|
一个 coding agent 单次任务就能烧掉 $1,000 的计算资源。AI 预算正在从 IT 部门（占营收 3-7%）溢出到业务线预算（占营收 60-80%），市场营销、销售、制造部门需要学会管理自己的 compute budget。

Token 成本从 IT 零花钱变成 CFO 议题：SaaS 定价模型的历史转折
431|
Aaron Levie 在播客中指向一个深层变化：AI 预算正在从 IT 部门（占营收 3-7%）溢出到业务线预算（占营收 60-80%）。这意味着市场营销 VP、销售 VP、制造 VP 现在需要学会管理自己的 compute budget——一个他们从未处理过的成本项。$20/人/月的 SaaS 定价模型建立在「软件边际成本趋近于零」的前提上，但 agent 每次运行都在烧真金白银。这不是一个技术问题，这是一个商业模式问题。谁先解决「用量定价 + 业务线可理解」这个方程，谁就能吃掉这波迁移的红利。
432|
433|
434|
变更管理才是真正的瓶颈
435|
Levie 提到一个反直觉现象：AI 能力突破得越快，企业刚铺好的基础设施就越快过时。这制造了一个悖论——技术越先进，企业部署反而越慢。当所有人都在 tokenmaxxing，真正赢的可能是那些把变更管理做对的人。「慢下来」在某个时间点上反而成了竞争优势。
