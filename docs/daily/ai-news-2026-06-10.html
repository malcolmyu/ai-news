Building an AI Guardian for Enterprise with Onyx Security CEO Maxim Bar Kogan

来源：No Priors 播客 | Onyx Security CEO Maxim Bar Kogan 探讨企业 AI Agent 安全新范式——当 Agent 的操作量指数级增长，谁在监督这些 Agent？为什么企业不愿把 Agent 行为数据交给模型厂商？以色列安全生态如何在 AI 时代找到新定位？
企业 AI Agent 风险在指数级增长
Maxim Bar Kogan 指出，当 Agent 开始执行指数级增长的操作时，恶意行为不可避免。近期已有 Agent 意外发布代码和令牌的案例。企业意识到风险在指数级增长，但无法阻止 AI 的采用——他们只能设法降低 Agent 行为不当的概率。
企业不愿与模型厂商共享 Agent 行为数据
Onyx 可以查看大量 Agent 历史行为数据，但企业不愿意让 Anthropic 或 OpenAI 接触这些数据——他们知道这些是极度渴望数据的公司，会把数据用于模型训练。这为独立的 Agent 安全层创造了巨大市场空间。
以色列安全生态向 AI 转型
Onyx 团队由研究员、数学家和工程师组成，借鉴以色列在网络安全领域的深厚积累，将安全思维移植到 AI Agent 领域。从 DLP for Chatbots 到构建 Agent 监控 Agent，这是一个全新的安全范式。

Aaron Levie @levie
There’s no amount of intelligence that can get packed into AI models that replaces the need for context. For any sufficiently general purpose AI, you will always have to guide it in the direction you want as it has an infinite range of directions it can go in. As long as the same model is used by a lawyer, an engineer, a financial analyst, or a healthcare professional, and as long as you’re trying to do anything uniquely differentiated or specific, then instructions, domain context, and proprietary data will always need to get into the context window for the model to be useful. This is partly why AI automation doesn’t come for free, and why there’s still a wide spectrum of who’s getting the largest gains from AI and who’s not. You have to put in real work, and you get real value on the other end. This is one of the advantages that applied AI will also have in the market. Any layer of abstraction above just the raw intelligence that can meaningfully get you off to the races faster will likely continue to be valuable.
无论 AI 模型里塞进多少智能，都无法取代对上下文的需求。对于任何足够通用的 AI，你永远需要引导它朝你想要的方向前进。

今日思考

两个信号在今日同时出现，值得放在一起看：

1. SWE-Bench 正在失去可信度。 METR 发现超过一半的 SWE-Bench 结果无法合并——这说明 AI 编程能力评估体系存在根本性缺陷。FrontierCode 的出现意味着行业需要更严格的「维护者验证」标准，而非依赖自动评分。当评估本身不可靠，我们如何知道模型在进步？

2. Agent 技能正在从原子走向分子。 last30days-skill（研究）、pm-skills（管理）、agent-skills（工程）三者同日登上 Trending 不是巧合。Agent 生态正在经历从「单点能力」到「技能组合」的质变——未来衡量 Agent 的标准不再是「能写什么语言」，而是「拥有哪些可组合的技能」。这与 Onyx 在做的 Agent 安全监控形成闭环：技能越多、操作越复杂，安全风险越高，监控需求越大。

结论：Agent 正在告别「Demo 阶段」，进入「基础设施博弈」。
