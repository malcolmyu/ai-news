Every 的 AI 化悖论：全公司最 AI 化，反而招了更多人。 Dan Shipper 与 COO Brandon 深度对谈：AI 把"昨天的专家能力"变得极廉价，任何人用 prompt 都能生成代码和文章。结果是大量"看起来不错但差点意思"的内容充斥着工作流——非专家产出激增，但每一样都需要真正的专家来收尾。Slack 里人和 agent 一样多，团队从 4 人扩张到 30 人还在招。核心论点：AI 不会抢走工作，但会重新定义什么是真正值钱的工作。

深度博客

OpenAI GPT-5.2 · Anthropic 事故复盘 · Managed Agents 架构演进

GPT-5.2 — "更聪明的模型训练更聪明的模型"
OpenAI 发布 GPT-5.2，定位为 RL 训练的最优策略模型。核心突破：用它作为 teacher model 训练出的编码 agent 在 SWE-Bench Verified 达到 82.6%（新 SOTA），Terminal-Bench 2.0 上性能是 Claude Opus 4.5 的 2.8 倍。目前仅向 Tier 5 API 用户开放。OpenAI 明确表示：未来最强的 coding agent 不是靠更好的 prompt，而是靠更强的 teacher model 做 RL——这暗示了一条模型能力自我强化的飞轮路径。
Claude Code 事故复盘 — 一行 prompt 引发的智商下降
Anthropic 公开复盘 4 月 Claude Code 性能退化：① Extended thinking 被 context management bug 意外丢弃，导致"健忘"和"重复"，最终是 Opus 4.7 在 code review 中找到这个 bug（Opus 4.6 没发现）；② 系统 prompt 为降低 verbosity 加上"不超过 25 词"一句，上线前通过所有 eval，但后续更广的 ablation 暴露了 3% 的"智商丢失"，已立即撤回。所有订阅用户用量限制被重置。后续改进：更多内部员工使用公开版本、系统 prompt 变更需跨模型完整评估、关键变更增加 soak period。
Managed Agents 架构解耦 — 把"大脑"和"手"分开
Anthropic 详述 Managed Agents 架构演进——本质是一次"操作系统的虚拟化"。之前 harness（编排层）、sandbox（执行环境）、session（会话日志）全塞在一个容器里，容器一挂全挂。解耦方案：大脑（harness）调用手（sandbox）变成标准化接口 execute(name, input) → string，容器可随时重建，harness 无状态可随时重启，session 作为持久化的 append-only log 独立存储。收益：P50 TTFT 下降约 60%，P95 下降超过 90%。安全模型也被重构——凭证永远不会进入 sandbox。
Managed Agents 支持自托管 Sandbox + MCP 隧道
企业级功能：agent 的 sandbox 可以跑在你自己基础设施上，支持 Cloudflare、Daytona、Modal、Vercel。MCP 隧道让 agent 能访问你内网的 MCP server，无需暴露公网端口。Amplitude、Clay、Rogo 等公司已在生产中使用。这表明 Anthropic 正从"我们帮你 sandbox"转向"你用自己的 sandbox，我们只管 agent 大脑"——生态位在向平台层移动。
核心信号：三条博客放在一起看——GPT-5.2 证明 RL teacher model 路线可行；Claude Code 事故复盘暴露"一行 prompt 就能掉 3% 智商"的脆弱性；Managed Agents 架构解耦展示 Agent 基础设施正走向标准化接口。三者共同指向：2026 年的 AI 正在同时经历模型能力的指数增长、工程实践的惨烈踩坑、以及基础设施的标准化——三个维度相互独立又彼此加速。

播客精选

AI & I：自动化一切之后，我们的团队反而翻了三倍

Every 的 Dan Shipper 与 COO Brandon 深度对谈，拆解了一个看似悖论的现象：Every 是全行业 AI 化程度最高的公司之一，Slack 里人和 agent 一样多，所有人每天用 Claude Code、Codex——但团队反而从 4 人扩张到了 30 人，还在招。核心论点来自 Dan 的文章《After Automation》。
AI 把专家变得廉价——然后专家更稀缺了
「任何会用 prompt 的人都能生成代码、写文章、做设计。结果是大量"看起来不错但差点意思"的内容充斥着工作流——非专家产出激增，但每一样都需要专家来收尾。」这就是 Every 扩招的原因：AI 放大了"草稿"，但判断什么值得做、什么时候该停下、哪里需要打磨——这些仍然需要人。
Agent 离人越远，价值越低
Dan 区分了两个概念：人类有"自主意愿"（agency），agent 只有"自动化执行能力"（autonomy）。AI 永远不会自己决定今天不想干活。Zeno 悖论的反转：你让 AI 做事，它惊艳你；然后它停下来看着你问"接下来怎么办？"——这个循环不会消失。
SOP 驱动的大公司呢？
Brandon 追问：在成熟流程驱动的大公司（如 ClickUp CEO 裁掉 22% 员工的案例），这个论点还成立吗？Dan 的回应：如果你只是骑在模型能力上，你没事；但如果你不去思考什么才是有价值的差异化工作，就会被替代。关键在于——你是在用 AI 放大你已经有的东西，还是在用 AI 创造新的价值。
这可能是今年以来关于"AI 与就业"最清醒的论述。不是 AI 抢走工作，而是 AI 重新定义了"什么才是真正值钱的工作"。AI 抹平了入门门槛，但拉高了"真正的专家"的天花板——因为人人都能生成中等质量的输出，只有真正的专家才能做出差异。

今日思考
AI 时代的新稀缺性：不是劳动力，是判断力
Dan Shipper 的观点和 OpenAI 的 GPT-5.2 路线放在一起看：GPT-5.2 证明更强的模型可以训练更强的 agent，AI 的生成能力在指数级提升；但 Every 的经验证明，生成能力越强，"什么是好的判断"就越稀缺。模型能生成一百个方案，但只有人能选出最好的那一个。AI 不是在替代人类——它在让"做"变得廉价的同时，让"判断"变得前所未有的贵。
基础设施标准化 × 模型能力飞跃 × 工程踩坑——三条线并行加速
今天的三组内容恰好覆盖了 AI 2026 的三个维度：① GPT-5.2 代表模型能力仍在高速增长——RL teacher model → student agent 的路线被验证可规模化；② Managed Agents 的架构解耦代表基础设施正在标准化——大脑和手分离、标准化接口、自托管选项；③ Claude Code 事故复盘代表工程实践仍在惨烈踩坑——一行 prompt 掉 3% 智商，context management bug 靠更强的模型才找到。三个维度独立推进但又相互加速。
今日一问：如果 GPT-5.2 训练的 agent 能写大部分代码，而 Anthropic 的 Managed Agents 能自动执行大部分操作——你剩下的独特价值，是熟练操作 AI 的能力，还是对"什么值得做"的判断力？
