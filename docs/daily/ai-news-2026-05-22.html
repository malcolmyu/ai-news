Box CEO 万言长文：AI Agent 部署不像云计算——云的用户是开发者和 IT，工作流不需根本改变。Agent 直接冲击每个人的底层工作流，意味着海量技术工作和变革管理。更残酷的是，每个模型更新都可能让之前能做的事变成可能，或让脚手架变得多余。他的结论：FDE（Forward Deployed Engineer）这个岗位会长期存在，是技术人员极好的职业路径。

MCP 深度

Dan Shipper：Stainless 的 MCP 四大哲学

Every CEO 详细拆解了 Stainless（3 亿美元被 Anthropic 收购）的 MCP 设计原则：① MCP 服务器要精炼——工具集小、命名精确、最小化 I/O、加 JSON filter 过滤冗余数据。② 动态模式——只给模型三个工具：列出端点、了解端点、执行端点。③ 公司大脑——Alex 让 Claude Code 持续运行，客户反馈和 SQL 查询存入 GitHub 形成知识库。④ MCP 的终极形态是代码执行——一个代码执行工具 + 一个文档搜索工具，而不是几百个 MCP 工具。

播客深度

AI & I：Stainless 与 MCP 的未来——Anthropic 3 亿美元收购的开发者工具公司

嘉宾：Alex Rattray（Stainless CEO）| 播客：AI & I（Dan Shipper）。Stainless 刚被 Anthropic 以 3 亿美元收购，这次对话系统性地剖析了 MCP 的现状与未来。
MCP 的宏大愿景是对的，但当前实现有问题
理想状态下，你对着 AI 说"帮我退款给 Dan"，AI 横跨 5 个 SaaS 工具、经过 15 个页面完成操作。但今天直接把几百个 API 端点暴露为 MCP 工具，会立刻烧光模型的上下文预算。工具爆炸是 MCP 当前最大的工程挑战。
为 LLM 设计「SDK」是全新的研究问题
人类花了很长时间才搞清楚怎么给 Python 开发者做好 SDK。我们还没搞清楚怎么给 LLM 做好"SDK"——这不是传统 API 设计问题，而是全新的研究领域：如何让模型高效理解和使用外部能力。
安全难题：自主权 vs 安全边界
你不想让 AI 在退款给 Dan 的同时，把所有用户的所有交易都退款了。当 Agent 拥有代码执行能力时，权限控制和审计日志变成了生死攸关的问题，而不仅仅是 nice-to-have。
终极方案：代码执行而不是工具调用
一个代码执行"超级工具" + 文档搜索，而不是几百个 MCP 工具。模型直接写代码调用 API 的 SDK，这从根本上解决了工具爆炸问题——因为模型本身就能推导和生成任何需要的调用逻辑。

趋势观察：今天的 GitHub Trending 被 AI Agent 工具链和技能生态彻底统治。CodeGraph 冲上第一（4,294 ⭐），Karpathy Skills 连续第二天上榜，Chrome DevTools 推出官方 MCP 服务器，dotnet 发布官方 AI 编程技能仓库。Agent 技能标准化和代码知识图谱正在成为基础设施层的核心战场——"给 Agent 更好的工具"正在变成比"训练更好的模型"更紧迫的问题。
为什么重要
AI 开始做真正的科学研究
OpenAI 的通用模型攻克 Unit Distance 问题不是普通的基准测试成绩——这是一个真实的数学开放问题，之前没有人解决过。Sam Altman 说这是"一个相当重要的里程碑"，而这句话我们未来几年会反复听到。当 AI 从"辅助工具"变成"科研贡献者"，知识生产的速度将发生阶跃式改变。这比任何一个模型分数都更重要。
MCP 从工具爆炸走向代码执行——范式级别的转向
Dan Shipper 对 Stainless 的分析揭示了一个重要转向：MCP 社区最初认为应该把每个 API 端点变成一个工具，现在发现这行不通——上下文窗口烧光，模型在工具选择中迷失。解决方案是回归第一性原理：给模型一个代码执行环境 + 文档，让它自己生成调用代码。这不仅更高效，而且从根本上解决了安全问题——可以在执行层做权限控制。
Agent 落地的真正瓶颈：人的变革管理
Aaron Levie 的万言长文点出了最容易被忽视的事实：云计算转型时，用户群体是开发者和 IT，工作流基本不变。Agent 直接冲击每个人的底层工作流——这意味着 AI 部署本质上是一次组织变革，而不仅是技术升级。他的结论——FDE 岗位长期存在——暗示了真正的瓶颈不是模型能力，而是"把能力翻译成工作流"的人。
Agent 技能标准化——基础设施层的军备竞赛
GitHub Trending 被 Agent 技能和工具链彻底统治：CodeGraph 4,294 ⭐、Karpathy Skills 连续上榜、Chrome DevTools 发布 MCP 服务器、dotnet 发布官方技能仓库。这标志着 Agent 生态正在从"各自摸索"进入"标准化竞争"阶段。谁能定义 Agent 技能的标准格式和分发方式，谁就掌握了 Agent 时代的基础设施层。
今日一问：当 OpenAI 的通用模型开始攻克数学开放问题，当 MCP 社区认识到"代码执行优先于工具调用"，当 Aaron Levie 说 AI 落地本质是变革管理而不是技术升级——我们是否正在进入一个"交互范式重构"的拐点？模型能力在急剧提升，但我们的工具设计、组织结构和人才模型还停留在上一个时代。代码执行优先于工具调用的转向，可能只是交互范式革命的第一块多米诺骨牌。
