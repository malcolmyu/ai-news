In this case, Claude acts as a coworker that any user can tap into in a shared way. We’ve already seen some agentic coding systems start to adopt this pattern (as well as OpenClaw and Hermes), and doing it for general purpose knowledge work continues to push the idea forward. As a result, what this means is that this agentic coworker needs its own set of resources, access to tools, and data to work with. This is not the same as you giving it access to your personal resources and tools, because the agent then could accidentally then share those out with anyone. 今日思考

AI 正从"工具"变成"同事"

今天的日报呈现出一条清晰的演进脉络。Claude 不再只是你个人使用的工具，而是以"共享同事"的身份加入团队——拥有自己的资源和权限，像任何团队成员一样协作。另一边，OpenMontage 展示了 AI 从代码助手扩展到完整视频工作室的能力，而 DESIGN.md 则定义了 AI 智能体如何"理解"设计系统。当 AI 从被动响应走向主动协作，从单点工具走向完整生产线，我们正在见证的不是简单的效率提升，而是工作方式的根本性重塑。正如 rauchg 所言：AI 将带来前所未有的创业浪潮——基础设施已在铺设，问题只在于你准备如何使用它。
