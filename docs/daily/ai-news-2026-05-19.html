AI & I by Every：Claude Code 如何成为你的第二大脑

158|
159| 嘉宾：Noah Breyer（Alethic 咨询公司创始人）| 主持人：Dan Shipper。Noah 展示了可能是最疯狂的 Claude Code 工作流：在地下室架一台家庭服务器，把整个 Obsidian 笔记库放进去，然后随时随地用任何设备跑 Claude Code。 160|
161|
162|
163|
164|
🧠 思考模式 vs 写作模式
165|
Noah 的核心秘诀是区分两个阶段。在思考阶段，他明确告诉 Claude Code「不要帮我写，只帮我思考、提问、整理」。大多数人一上来就让 AI 生成成品，但实际上 AI 最强的能力是作为思维伙伴。
166|
167|
168|
169|
170|
📂 项目式笔记管理
171|
他的 Obsidian 里每个项目有自己的文件夹，内含 research（研究文章）、chats（聊天记录）、daily progress（AI 自动总结当天的思考和收获）。Claude Code 跨文件阅读、连接信息、提炼洞见。
172|
173|
174|
175|
176|
📱 手机端生产力革命
177|
通过 Tailscale 隧穿到家里的 Linux 服务器，Noah 可以在手机上跑完整版 Claude Code。「周二送完孩子上校车，我在早餐桌上用手机工作了整整两小时——做真正的思考和研究，不只是回复消息」。他甚至可以在户外池边用手机提交代码 PR。
178|
179|
180|
181|
182|
🎤 Grok Voice Mode 称王
183|
Noah 强烈推荐 Grok 的语音模式，远超 ChatGPT 和 Gemini。Grok 的「工具调用能力碾压其他语音模型」，能一边对话一边做真正的网络搜索研究。他在五小时长途驾驶中和 Grok 讨论了一路 transformer 的 self-attention 原理。
184|
185|
186|
187|
188|
🛠️ 推荐工具栈
189|
Obsidian（笔记）、Tailscale（网络隧穿）、mini PC + Linux（家庭服务器）、Grok Voice Mode（车载/移动研究）、Gemini Flash（批量文件重命名等轻量任务）、LLM CLI（Simon Willison 的命令行 LLM 工具）
190|
191|
192|
193|
194| 关键洞察：Noah 展示的不是「AI 替代你写作」，而是「AI 帮你构建思维基础设施」。当你的笔记库、服务器、AI agent 三者打通，你的手机就变成了一个可以随时进行深度工作的终端。这不是工具升级，而是工作方式的范式转移——从「人操作电脑」到「人+AI 共同思考」。 195|

🧩 Agent 技能包：从「工具调用」到「专业能力」
313|
GitHub Trending 上 academic-research-skills、agent-skills、scientific-agent-skills 三个项目同时上榜，不是巧合。社区正在从「怎么让 Agent 调用工具」进化到「怎么让 Agent 具备专业领域能力」。这就像从教一个人用榔头，到培养一个完整的工匠——前者是 tool use，后者是 skill。CLI-Anything 也在同一方向上：把一切变成 Agent 可调用的接口。这意味着 AI 编程的下一个战场不是模型能力，而是技能生态。
314|
315|
316|
🔮 第二大脑：AI 不是替代思考，是升级思考
317|
Noah Breyer 的工作流给了一个清晰的答案：AI 的真正价值不是替你写作，而是帮你构建思维基础设施。区分「思考模式」和「写作模式」是一个简单但强大的方法论——在思考时让 AI 提问、整理、连接信息；在写作时才切换到生成模式。这呼应了 Levie 的观点：用 AI 的专家永远碾压用 AI 的新手。工具不会抹平差距，只会放大差距。
318|
319|
320|
321|
322| 今天的三条主线：① Agent 技能包生态爆发——AI 编程从「怎么调用」进化到「具备什么能力」；② Claude Code 成为第二大脑——不是替你写，而是帮你思考；③ AI 时代的职业焦虑与解药——专家+AI 的组合才是终极形态，工具放大差距而不是抹平差距。核心共识：建造 > 空谈，深度 > 速成。 323|
